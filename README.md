# PEAK VR Mod

A PCVR conversion for **PEAK**, made by **SabSnake** and published by **HavocBoxMedia**.

## Highlights

- SteamVR / OpenXR PCVR support
- Valve Index and Meta Quest PCVR controller-aware layouts
- Physical climbing, grabbing and interaction
- Movement-based light / medium / heavy throwing
- Wrist inventory, backpack interaction and free-hands fallback
- VR settings, comfort options and control rebinding
- OBS / spectator camera tools with centered view and custom FOV
- One-click Windows installer

## Install

1. Download the latest installer from **Releases**.
2. Run `PEAKVR-Havoc-Installer-v1.0.exe`.
3. Confirm the detected PEAK folder.
4. Click **Install / Update**.
5. Start SteamVR.
6. Launch PEAK normally through Steam.
