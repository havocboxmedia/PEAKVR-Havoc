# PEAK VR Mod v1.0

First main public release of PEAK VR Mod by **SabSnake**, published by **HavocBoxMedia**.

## Highlights
- SteamVR / OpenXR PCVR support
- Valve Index and Meta Quest PCVR controller-aware layouts
- Physical climbing, grabbing and interaction
- Movement-based light / medium / heavy physical throwing
- Wrist inventory, backpack interaction and free-hands fallback
- VR settings, comfort options and controller rebinding
- OBS / custom spectator camera tools
- Centered camera view and POV quick-select
- One-click Windows installer

## Install
1. Download **PEAKVR-Havoc-Installer-v1.0.exe**.
2. Run the installer.
3. Confirm the detected PEAK folder.
4. Click **Install / Update**.
5. Start SteamVR.
6. Launch PEAK normally through Steam.

The **Friends ZIP** contains the installer plus a short install guide.
